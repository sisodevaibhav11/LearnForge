# LearnForge Frontend Client

Modern, responsive Single Page Application (SPA) built with React 19, Vite, and Tailwind CSS v4.

## Features
- **Split-Screen Interactive Document Workspace**: View documents alongside AI chat, flashcards, or quizzes.
- **Dark/Light Mode**: Full theme toggle with persistent state.
- **Spaced Repetition & Flashcards**: Interactive flip-card review system.
- **Interactive Quizzes**: Timer, multi-question progression, and instant scoring breakdown.
- **Study Analytics Dashboard**: Visual progress metrics and study streaks.

## Available Scripts
In the frontend directory:
- `npm run dev`: Starts the Vite local development server on `http://localhost:5173`.
- `npm run build`: Bundles the production build into `dist/`.
- `npm run preview`: Previews the production build locally.
